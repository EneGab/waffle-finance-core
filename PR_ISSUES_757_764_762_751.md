# Pull Request: Idempotency, Lifecycle, Event Ordering & Smoke Tests

## Issues
- #757: Duplicate relayer recovery actions (idempotency tracking)
- #764: Event ordering and staleness detection for resolver
- #762: Explicit resolver lifecycle with safe transitions
- #751: Smoke tests for relayer failure scenarios

## Summary

This PR implements comprehensive reliability improvements for the WaffleFinance core system:

1. **Idempotency Tracking** - Prevents duplicate transaction submissions in recovery operations
2. **Event Ordering** - Adds guards for out-of-order events and stale block detection
3. **Explicit Lifecycle** - Formalizes resolver lifecycle with safe state transitions
4. **Smoke Tests** - Realistic failure scenarios for local development testing

## Usage Examples

### Idempotency

```typescript
import { IdempotencyManager } from '../src/idempotency.js';

const manager = new IdempotencyManager();

// Check if safe to attempt
if (!manager.canRetry('order-123', 'claim')) {
  log.warn('Cannot retry action', { reason: manager.getRecoveryContext('order-123', 'claim').retryReason });
  return;
}

// Record attempt
const record = manager.record('order-123', 'claim', 'cid-abc');

// Submit transaction
const txHash = await submitClaim();
manager.submitted('order-123', 'claim', txHash);

// Complete after mined
manager.complete('order-123', 'claim', txHash, blockNumber);
```

### Event Ordering

```typescript
import { EventOrderGuard, EventOrderMonitor } from '../src/event-ordering.js';

const guard = new EventOrderGuard();
const monitor = new EventOrderMonitor();

guard.updateChainHead('ethereum', newHead);

const record = guard.validateEvent(metadata);

if (!record.valid) {
  log.warn('Event rejected', { reason: record.rejectionReason });
  return;
}

processEvent(event);
```

### Lifecycle

```typescript
import { ResolverLifecycle } from '../src/lifecycle.js';

const lifecycle = new ResolverLifecycle(log);

// Start
lifecycle.transition('starting');
await startListeners();
lifecycle.transition('running');

// Pause
lifecycle.transition('pausing');
await drainInFlightWork();
lifecycle.transition('paused');

// Resume
lifecycle.transition('restarting');
lifecycle.transition('starting');
lifecycle.transition('running');

// Stop
lifecycle.transition('stopping');
await cleanup();
lifecycle.transition('stopped');
```
